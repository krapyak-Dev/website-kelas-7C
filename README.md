# Website Kelas 7 — Dark Mode

Website statis sederhana untuk GitHub Pages. Tidak memerlukan database atau proses build.

## Isi folder
- `index.html` — struktur halaman
- `style.css` — desain dark mode dan tampilan responsif
- `script.js` — data anggota, jadwal, pengumuman, dan piket

## Cara mengedit
Buka `script.js` lalu ubah:
- `members` untuk nama dan jabatan anggota
- `schedule` untuk jadwal pelajaran
- `announcements` untuk pengumuman
- `duties` untuk jadwal piket

Foto galeri ada di bagian `#galeri` pada `index.html`. Ganti URL gambar contoh dengan foto kelas yang sudah mendapat izin.

## Publish dengan GitHub Pages
1. Login ke https://github.com
2. Klik **New repository**.
3. Beri nama, misalnya `website-kelas-7`. Pilih **Public**, lalu **Create repository**.
4. Klik **Add file → Upload files**, lalu unggah `index.html`, `style.css`, `script.js`, dan `README.md` (bukan folder ZIP).
5. Klik **Commit changes**.
6. Buka **Settings → Pages**.
7. Di bagian **Build and deployment**, pilih **Deploy from a branch**.
8. Pilih branch **main** dan folder **/(root)**, lalu klik **Save**.
9. Tunggu beberapa menit. Link website akan muncul di bagian GitHub Pages, biasanya berbentuk `https://USERNAME.github.io/website-kelas-7/`.

## Catatan privasi
Karena ini website publik, mintalah izin sebelum memasang foto atau data teman. Hindari mencantumkan nomor telepon, alamat rumah, tanggal lahir lengkap, atau informasi pribadi lainnya.
